Studio organisé, liens personnels fixes, format de diffusion et instance unique.

- Studio en quatre onglets : Thèmes, Animation, Habillage et Diffusion.
- Artiste — Titre en gras sur une ligne avec une icône de musique transparente à gauche.
- Deux liens personnels persistants par profil Windows : portrait et paysage. Identifiant et port conservés ; aucun changement silencieux si le port est occupé.
- Nom du processus stable : ZELYVARO Audio Live.exe.
- À chaque copie du lien TikTok / OBS : choix Portrait 9:16, 1080 × 1920, ou Paysage 16:9, 1920 × 1080. Dernier choix mémorisé.
- Le lien conserve son format, sans déformer le rendu. Régler les dimensions de la source Navigateur dans le logiciel de live comme indiqué dans le dialogue ; une page ne peut pas changer automatiquement ces propriétés.
- Aperçu de diffusion dans le format choisi ; textes ajustés à la hauteur disponible.
- Un second lancement affiche la fenêtre déjà ouverte, même depuis un autre dossier ou après rangement en zone de notification.
- La croix range le logiciel dans la zone de notification et laisse capture et diffusion actives. Quitter reste accessible par les menus.
- Reprise d’une ancienne instance 1.2.0 pendant la transition vers le verrouillage unique.

Les six visualiseurs, compositions, fonds, logos transparents et mises à jour GitHub sont conservés.
